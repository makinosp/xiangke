# Rust Implementation Reference Guide

When working on Rust implementation tasks (files matching `**/*.rs`):

1. **Authoritative Source**: Always consult `references/rust-reference/src/` for
   the official language specification.
2. **Verification**: Before finalizing any complex Rust construct, verify it
   against the corresponding chapter in the Rust Reference.
3. **Context**: Use the files in `references/rust-reference/src/` as the primary
   ground truth for language behavior.
